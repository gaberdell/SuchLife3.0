# SUCH LIFE - CRAFTING #

## Crafting System ##

Crafting is an integral system for a survival crafter.

Players can craft tools, armor, and other items in the always accessible crafting grid via resources they have to gather.

These crafted items provide players an easier way to clear content, and enable them to clear harder content.

Some resources, necessary for crafting further gear, can only be gathered with crafted items, reinforcing the integral aspect of crafting.


## Item Categories ##

| Category | Items Included |
| ----------- | ----------- |
| Resources | Sticks | 
| Blocks | Bricks |
| Resource Gathering | Pickaxe |
| Combat | Sword, Crossbow, Spear |
| Protection | Armor, Shield |
| Consumables | Food, Potions |
